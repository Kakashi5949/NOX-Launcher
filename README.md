# NØX Launcher

**BE DIFFERENT. PLAY SMART.**

NØX Launcher — лаунчер для Minecraft Java Edition.

## Планируемые возможности
- Минималистичный черно-белый интерфейс
- Вход по игровому нику
- Minecraft Java 1.21.11
- Поддержка Fabric
- Настройка оперативной памяти (RAM)
- Запуск игры через лаунчер

## Статус проекта
Проект находится в разработке. Функции установки и запуска Minecraft пока создаются.# NØX Launcher
